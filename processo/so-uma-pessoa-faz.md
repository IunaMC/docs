# O que só uma pessoa faz

O que não tem automação hoje. A revisão desta lista, com o porquê de cada
item e o que pode virar script, está em andamento. Até lá, a página fica como
está.

- Enviar as configs ao servidor e reiniciar pelo painel
  ([processo](enviar-configs.md)).
- Colar a descrição e trocar as imagens do projeto na CurseForge, que não tem
  API para isso (o `curseforge.py descricao` do modpack gera o texto), e
  acompanhar a revisão dos arquivos.
- Pedidos de permissão no Modrinth e a moderação de lá.
- Atalhos do domínio ([arquitetura](../explicacao/arquitetura.md#atalhos-do-domínio)).
- Cargos: LuckPerms pelo console e sincronia com o Discord
  ([cargos](../servidor/cargos.md)).
- Gerar e renovar os tokens dos workflows
  ([segredos do modpack](https://github.com/IunaMC/modpack/blob/main/docs/referencia/segredos.md)).
