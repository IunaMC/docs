# Documentação do IUNA

Como a operação do IUNA funciona de ponta a ponta: a arquitetura, o processo
de versão entre os repositórios, os cargos do servidor e as decisões que
moldaram tudo isso.

Cada repositório documenta o que muda junto com o código dele. Este reúne o que
atravessa repositórios. O critério está na
[decisão 0003](decisoes/0003-documentacao-em-repo-proprio.md).
